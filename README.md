# 基于 TI MSPM0G3507 与嘉楠 K230 的车载平衡滚球运动控制系统

本项目为 2026 年全国大学生电子设计竞赛（NUEDC）H 题作品完整嵌入式底层源码。
系统以 TI MSPM0G3507 微控制器为运动控制核心，结合嘉楠 K230 边缘视觉端侧计算平台，实现双轮差速底盘高精度循迹与车载顶置摆杆小球动态平衡的强耦合协同控制。

## 1. 核心竞赛技术指标与实测表现

针对官方赛题在直道（1.5m）、弯道（R=0.5m 环形赛道）以及停车精度的严格要求，经软硬件协同闭环调试，实测性能如下：

* 静止往返控制：在车体静止工况下，摆杆小球在目标范围（±5cm）内快速往返稳定运行，单程用时稳定在 4.2 秒以内（官方上限 5 秒）。
* 动态循迹抗扰：在车体以 0.5m/s 高速过弯运动过程中，引入余弦加速度规划抑制离心加速度冲击，全程小球稳定不脱轨，单圈运行用时 26.8 秒（官方上限 30 秒）。
* 终端精确定位：终点停车制动后，车体中心与停机线偏差小于 1.8cm（官方指标要求小于 2cm）。

## 3. 系统硬件架构与外设资源分配

系统以 TI MSPM0G3507 为核心主控，协调端侧视觉感知、姿态解算、底盘驱动与顶置平衡机构。硬件通信拓扑与外设资源分配均与工程底层源码严格一致：

| 硬件模块 / 外设对象 | 物理通信接口 | MCU 硬件资源分配 (MSPM0G3507) | 业务功能与数据流向 |
| :--- | :--- | :--- | :--- |
| **嘉楠 K230 (端侧视觉)** | 异步串口 (UART) | UART0 (PA10/PA11, 115200bps) | 中断接收小球实时坐标 (EE帧) 与目标平衡位置 (FF帧) |
| **六轴姿态传感器 (JY61P)** | 软件模拟 I2C | GPIO (PA1 SCL / PA0 SDA) | 非阻塞状态机定时采集车体偏航角 (Yaw) 与角速度 |
| **底盘双路直流减速电机** | 硬件 PWM + GPIO 方向 | TIMA1 (PB4/PB1, 10kHz PWM) + 4路方向引脚 | 底盘差速速度闭环控制与循迹差动驱动 |
| **双路霍尔测速编码器** | GPIO 外部中断输入 | GPIOA (PA15/PA16/PA17/PA22) | 双边沿中断触发，软件判相实现 4 倍频轮速与里程计量 |
| **平衡摆杆闭环步进伺服** | 串口总线指令协议 (SMD) | UART3 / UART2 (PB12/13, PA21/24) | 串口发送脉冲位置闭环指令，实现摆杆高精动态倾角补偿 |
| **灰度传感器阵列 (循迹)** | 并行数字 GPIO 输入 | 8 路数字输入引脚 (PA/PB 混合映射) | 跑道黑线边缘实时检测与转向偏航偏差提取 |
| **本地状态显示屏 (LCD)** | 硬件 SPI + 控制 GPIO | SPI1 (PB9 SCLK / PB8 MOSI, 32MHz) + 4路控制引脚 | 赛场参数在线调试、实时波形监控与系统状态显示 |
| **无线调试模块 (HC-05)** | 异步串口 (UART) | UART1 (PB6/PB7, 115200bps) | 上位机无线遥测、PID 实时在线调参与模式切换 |

## 4. 软件工程分层架构

工程严格按照分层解耦规范进行模块化构建：

* 业务应用层 (`/app`)：
  * `task.c` / `task.h`：轻量级时间片轮询任务调度器。
  * `app_protocol.c` / `process_frame.c`：视觉数据帧与状态机解析，负责 K230 目标坐标解码与数据校验。
  * `app_lcd.c`：参数在线监控与系统状态调试界面。
* 硬件驱动层 (`/Hardware`)：
  * `motor_ctrl.c`：底盘直流电机驱动与 PWM 占空比输出控制。
  * `Encoder.c`：GPIOA 外部中断双边沿四倍频脉冲捕获与轮速里程解算。
  * `bsp_gyro.c` / `bsp_gyro.h`：软件模拟 I2C 驱动与 JY61P 六轴陀螺仪姿态角解算。
  * `gw_gray.c` / `gw_gray.h`：8 路数字灰度循迹阵列检测与跑道偏差提取。
  * `hw_lcd.c` / `hw_spi.c`：硬件 SPI1 LCD 彩色液晶屏显示驱动与底层传输。
  * `smd.c` / `smd.h`：串口总线 PD42 闭环步进伺服电机驱动与位置闭环控制。
  * `bsp_hc05.c` / `bsp_hc05.h`：UART1 蓝牙无线通信与上位机调参协议交互。
* 算法与中间件层 (`/middle`)：
  * `timer.c`：TIMA0 5ms 确定性高精度控制中断，承载核心 PID 闭环算法与余弦加减速插值计算。
  * `usart.c`：带环形缓冲区的底层串口多路驱动封装 (UART0/UART1/UART2/UART3)。
  * `delay.c`：微秒/毫秒级硬件定时延时服务。
* 底层硬件配置 (`SysConfig`)：
  * `empty.syscfg`：TI 官方图形化引脚分配、时钟树、定时器及外设寄存器配置描述文件。

## 5. 核心控制算法与技术难点

1. 5ms 确定性闭环控制周期：
   利用硬件定时器 TIMA0 提供稳定的 5ms 时间基准，将电机测速、姿态解算与 PID 输出计算严格限制在中断服务例程中执行，彻底消除任务调度抖动对微分项的干扰。
2. 串级 PID 动态抗扰：
   设计外环位置环（小球坐标偏差）与内环姿态/速度环串级控制拓扑，配合输出限幅与积分抗饱和（Anti-Windup）算法，抑制剧烈起停时的超调。
3. 余弦 S 曲线轨迹规划：
   在加速与制动阶段引入余弦平滑加减速算法，保证底盘加速度连续无阶跃，有效降低小球在加减速瞬间的惯性冲击。
